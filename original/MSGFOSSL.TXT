


         Message fossil API - by Mark May - MK Software


         The message fossil itself may be implemented through various
         methods (Device driver, TSR, or a program that installs an
         ISR and shells to an application program).  The method of
         providing the ISR is transparant to the application program

         Interrupt $F2 is the default.  This may be overriden by
         setting an environment variable, ie:

         Set MSGFOS=32

         would set the interrupt to $32.

         --------------------------------------------------------------

         Function $10 = Initialize and Open (Initializes/allocates and
         opens a message base.  The format of a MsgAreaId is dependent
         on the message base and may be up to 128 characters long. A
         message handle is returned that must be used for access to
         remaining message functions.)

         Input
             AH = $10
             ES:BX -> points to null terminated Msg Area Id
             CH = non-zero value means create if non-existant

         Output
             AL = Message Handle
             CL = returns result code
                  (0=success 1=does not exist 2+ = error)

         --------------------------------------------------------------

         Function $11 = Close and release (Close the message base and
         free up allocated memory)

         Input
             AH = $11
             AL = Message Handle

         Output
             CL = result code

         --------------------------------------------------------------

         Function $12 = Lock message base (normally handled by the
            write message function, but locking, writing a block of
            messages and then unlocking may be faster)

         Input
             AH = $12
             AL = Message Handle

         Output
             CL = Result Code

         Function $26 = Get message location id (returns a long
             identifier that may allow faster message seeking
             than using a seek first to return to a previously
             accessed message.  Some implementations may pass this
             as a file position or record number, but you should
             make no assumptions about its content.)

         Input
             AH = $26
             AL = Message Handle

         Output
             CL = Results
             ES, BX = Message location id

         --------------------------------------------------------------

         Function $27 = Set message location (seeks to message that
             matches the message location id)

         Input
             AH = $27
             AL = Message Handle
             ES, BX = Message location id

         Output
             CL = Results

             AH = $48
             AL = Message Handle

             CL = Results
             ES, BX = message attributes


                                 Attributes

                  ES                                BX
         $0001 = Local                       $0001 = Crash Netmail
         $0002 = Received                    $0002 = Kill/Sent
         $0004 = Private                     $0004 = Sent
         $0008 = Echoed                      $0008 = Request Receipt
         $0010 = File Request                $0010 = Request Audit
         $0020 = File Attach                 $0020 = Return Receipt

         Function $61 = Get message text string

         Input
             AH = $61
             AL = Message Handle
             CH = Maximum length
             ES: BX -> Points to a 256 byte buffer

             CL = Results
             DH = Attributes ($0001 = softwrapped text)
             DL = EOM ($FF = no more text, $00 = normal)

         --------------------------------------------------------------

         Function $62 = Get Text position (returns a long identifier
         to current position within the text - Note that this is *not*
         a character counter (although some implementations may use a
         character counter as the identifier).  It is to be used only
         to reseek to a text position marked earlier.)

         Input
             AH = $62
             AL = Message Handle

         Output
             ES: BX = Message text position indicator
             CL = Results

         --------------------------------------------------------------

         Function $63 = Set text position (Sets text position based
         on a long identifier previously returns by a call to function
         $62.)

         Input
             AH = $63
             AL = Message Handle
             ES: BX = Message text position indicator

         Output
             CL = Results

         --------------------------------------------------------------

         Function $6A = Put text string into message being created

         Input
             AH = $6A
             AL = Message Handle
             ES: BX -> points to buffer containing text string
             DL = $01 means add hard CR after string ($00 means
               text is assumed to be soft-wrapped)

         Output
             CL = Results
